# International Breweries SQL Analysis

## Project Overview

This project analyzes sales and profit data from International Breweries across multiple West African countries using SQL.

The analysis focuses on profitability, brand performance, customer consumption patterns, regional trends, and sales performance between 2017 and 2019.

---

## Dataset

The dataset contains information on:

- Countries
- Brands
- Sales Representatives
- Regions
- Profit
- Quantity Sold
- Months
- Years

---

## Objectives

The project aims to answer key business questions such as:

- Which country generated the highest profit?
- Which year was most profitable?
- Which brewery brand performed best?
- What are the consumption patterns across regions?
- Which products dominate different markets?

## Data Preparation

Several transformations were performed before analysis:

- Created Territory column
- Classified products as Beer or Malt
- Converted Profit column to numeric format
- Cleaned missing values

---

## Key Findings

- Nigeria generated the highest total profit.
- 2019 was the most profitable year.
- Budweiser was the leading brand in Senegal.

## Insights

- Nigeria represents a critical revenue market for the company.
- Brand preferences vary across countries, indicating the need for localized marketing strategies.
- Strong Budweiser performance suggests opportunities for further market penetration in Senegal.
